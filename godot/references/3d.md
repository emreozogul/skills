# Godot 4 — 3D mode (low-poly action games)

Same skill, 3D. The *concepts* from the 2D refs port — `enum`+`match` state machines, the Health/Hurtbox/Hitbox composition, the game-feel checklist, the `Events` bus, the run-to-verify discipline. This file is the 3D-specific swaps. Pairs with `asset-pipeline` (Kenney/Quaternius/Synty low-poly packs) for the art.

**Low-poly is the fast lane for a solo dev** because cohesive rigged+animated CC0/$ packs exist — you *assemble* a world instead of modeling it. Build the game in one pack's style; see `asset-pipeline` → the `lowpoly` tag.

## The look (set once)

- **WorldEnvironment** + a **DirectionalLight3D** (the sun). Add an HDRI from the vault as `Environment.sky` for free ambient light + reflections (`ph-hdri-*`).
- Low-poly reads best with **slightly soft shadows + flat-ish lighting**. Packs ship their own materials — don't fight them.
- Optional "pixel-3D" stylization: render the game to a low-res `SubViewport` and upscale (PS1 vibe). Skip until the loop is fun.
- Texture filter: low-poly atlases usually want **Nearest** if the texture is pixel-art, else leave default.

## Player — CharacterBody3D (camera-relative)

```gdscript
class_name Player3D
extends CharacterBody3D

@export var speed := 6.0
@export var accel := 40.0
@export var turn_speed := 12.0
@export var gravity := 20.0

@onready var model: Node3D = $Model              # the imported .glb instance
@onready var anim: AnimationPlayer = $Model/AnimationPlayer
@onready var cam: Camera3D = get_viewport().get_camera_3d()

func _physics_process(delta: float) -> void:
	var in2 := Input.get_vector("move_left", "move_right", "move_up", "move_down")
	# Camera-relative: "up" = away from the camera, whatever its yaw.
	var yaw := cam.global_rotation.y if cam else 0.0
	var dir := Vector3(in2.x, 0.0, in2.y).rotated(Vector3.UP, yaw)

	var target := dir * speed
	velocity.x = move_toward(velocity.x, target.x, accel * delta)
	velocity.z = move_toward(velocity.z, target.z, accel * delta)
	velocity.y -= gravity * delta            # manual gravity in 3D
	move_and_slide()                          # uses velocity (Vector3), no args

	if dir.length() > 0.1:
		var look := atan2(dir.x, dir.z)       # face travel direction
		model.rotation.y = lerp_angle(model.rotation.y, look, turn_speed * delta)
		anim.play("Walk")                     # Kenney/Quaternius/Synty rig anim names
	else:
		anim.play("Idle")
```

## Camera — fixed-angle follow (ARPG/Moonlighter-style)

For a top-down-ish action RPG, a fixed-angle camera that *follows position but never rotates* reads cleanly. (For over-shoulder, use a `SpringArm3D`; for the no-code path, **Phantom Camera** does 3D too — see `ecosystem.md`.)

```gdscript
extends Camera3D
## Drop in the level; set `target` to the player. High + back = ~50° down.
@export var target: Node3D
@export var offset := Vector3(0, 13, 10)
@export var follow := 8.0

func _physics_process(delta: float) -> void:
	if not target: return
	global_position = global_position.lerp(target.global_position + offset, follow * delta)
	look_at(target.global_position, Vector3.UP)   # guard: target must differ from cam pos
```

## Importing pack models (.glb)

1. Drop the `.glb` (Kenney/Quaternius/Synty/AI export) into the project → Godot imports it as a scene: `MeshInstance3D` + `Skeleton3D` + **`AnimationPlayer`** (the rig's clips).
2. Instance it as the player's `Model` child. Play clips by name: `anim.play("Run")`. (Packs name them `Idle`/`Walk`/`Run`/`Attack`/`Die`.)
3. **Collision is separate from the visual** — add a `CollisionShape3D` (a `CapsuleShape3D` for a character) directly on the `CharacterBody3D`, sized to the model. For static level geometry, use the importer's *Create Trimesh Collision* (advanced import) or a `StaticBody3D`.
4. **Scale check:** glTF is Y-up, meters. Synty/Kenney are ~1 unit = 1 m. If a model is 100× off, fix scale on import, then `Ctrl+A`-equivalent isn't needed — set import scale.

## Combat — Area3D hit detection (same composition)

Reuse the `Health` node from `combat-components.md` verbatim (it's dimension-agnostic). The boxes become 3D:

```gdscript
class_name Hurtbox3D
extends Area3D
@export var health: Health
func _ready() -> void:
	if health == null:
		health = get_parent().get_node_or_null("Health")
func receive_hit(dmg: int, from: Vector3) -> void:
	if health: health.take_damage(dmg, from)   # take_damage(amount, from: Vector2) → widen `from` to Variant, or store as Vector3
```
```gdscript
class_name Hitbox3D
extends Area3D
@export var damage := 6
@export var knockback := 6.0
func _ready() -> void:
	monitoring = false
	area_entered.connect(_on_area_entered)
func _on_area_entered(a: Area3D) -> void:
	if a is Hurtbox3D:
		a.receive_hit(damage, global_position)
		var t := a.get_parent()
		if t and t.has_method("on_hurt"): t.on_hurt(global_position, knockback)
		GameFeel.hit_pause(6)
		GameFeel.shake(0.35)
```
Collision layers: same scheme as 2D (`combat-components.md`) — they're shared 2D/3D layer names but 3D bodies use the **3D** layer/mask. Hitbox monitors during active frames; toggle from the attack animation via an AnimationPlayer call-method track or a timer.

## Game feel in 3D — what ports, what changes

| Effect | 3D change |
|---|---|
| **Hit-pause** | **Identical** — `Engine.time_scale` is global. The `GameFeel.hit_pause()` from `game-feel.md` works as-is. |
| **Screen shake** | Now on **Camera3D**. Add a trauma-based positional offset *after* the follow-lerp: `cam.global_position += rand_unit_vec3() * trauma² * MAX`. Keep MAX small (~0.2 m). |
| **Knockback** | A **Vector3** on the XZ plane: `velocity += (global_position - from).normalized() * force` (zero the Y). |
| **Hurt flash** | Flash the model's material: tween `StandardMaterial3D.emission_energy` up then down, or a `next_pass` flash shader on the `MeshInstance3D`. (Modulate doesn't exist on 3D meshes.) |
| **Squash/stretch** | Scale the **Model** `Node3D`: `model.scale = Vector3(1.15, 0.8, 1.15)` then tween back. |
| **Damage popup** | A `Label3D` (billboarded) at the hit point, tween up + fade. |

So `GameFeel` grows a 3D path: `set_camera()` accepts a `Camera3D`, and `_process` applies the shake to its `global_position` (or an offset node) instead of `Camera2D.offset`.

## Enemy AI — NavigationAgent3D chase

```gdscript
extends CharacterBody3D
@onready var agent: NavigationAgent3D = $NavigationAgent3D
@onready var player := get_tree().get_first_node_in_group("player")

func _physics_process(delta: float) -> void:
	if not player: return
	agent.target_position = player.global_position
	var next := agent.get_next_path_position()
	var dir := (next - global_position).normalized()
	velocity.x = dir.x * 4.0
	velocity.z = dir.z * 4.0
	velocity.y -= 20.0 * delta
	move_and_slide()
```
Requires a **`NavigationRegion3D`** with a baked `NavigationMesh` covering the level. For open arenas, skip the navmesh and chase directly (`dir = (player.global_position - global_position)`). Add the player to a `"player"` group (`add_to_group("player")`).

## 3D gotchas

- `move_and_slide()` — no args; set `velocity: Vector3`; gravity is **manual** (`velocity.y -= g*delta`).
- `look_at(target, UP)` **errors if target == position** — guard, or use it only on a camera that's offset.
- Smooth turning: `lerp_angle(model.rotation.y, target_yaw, k*delta)`, not raw `=`.
- Rotate the **model child**, not the `CharacterBody3D` (rotating the body spins its collision + camera basis).
- Navigation needs a frame to sync: `await get_tree().physics_frame` before the first `get_next_path_position()`.
- `get_viewport().get_camera_3d()` returns the active camera — handy for camera-relative input.
- Group lookup: `get_tree().get_first_node_in_group("player")` beats hard `$"../../Player"` paths.
